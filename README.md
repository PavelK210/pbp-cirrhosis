# Исходы цирроза · Kaggle Playground S3E26

**01_merged_eda.ipynb** объединяет предоставленный `main.ipynb` и EDA из ветки `Nikhat-DA`. В начале есть таблица сравнения источников. Далее идут проверка повторяющихся профилей, анализ признаков и разбор того, какие измерения доступны в момент прогноза. [Исходный EDA](https://github.com/PavelK210/pbp-cirrhosis/blob/d45aa4cce28434bc59395feca82fd4b78887b77d/notebooks/EDA.ipynb)

**02_modeling.ipynb** начинается с разбиения данных. В нём сравниваются масштабы, новые признаки, балансировка, порог для редкого класса и два семейства моделей. Поиск по сетке и Optuna получают одинаковый бюджет. В конце — отложенная проверка, разбор ошибок и запись `submission.csv`. Ориентиром для последовательности экспериментов послужили стадии классификации, регуляризации, проверки и инженерии признаков учебного проекта. Числа в работе получены на своих разбиениях.

## Открыть подготовленную папку на Рабочем столе

В ней уже есть окружение Python 3.12. Из терминала запустите JupyterLab.

```sh
cd ~/Desktop/Cirrhosis_Research_2026-11-23
.venv/bin/jupyter lab
```

В JupyterLab откройте нужный ноутбук. Сохранённые таблицы, графики и выводы видны сразу. Для повторного расчёта перезапустите ядро и выполните все ячейки сверху вниз. Второй ноутбук читает CSV самостоятельно и при повторном запуске обновляет `submission.csv` в той же папке.

## Перенести проект на другой компьютер

Распакуйте архив целиком. В корне проекта, рядом с ноутбуками и `requirements.txt`, выполните команды для macOS или Linux.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/jupyter lab
```

Оба ноутбука используют `study_data.py`. В нём заданы 17 полей для прогноза, проверки структуры CSV и групповые разбиения. Каталог `data/` содержит `train.csv`, `test.csv` и `sample_submission.csv`. Их содержимое совпадает с файлами данных в указанной ветке исходного проекта.
